=================================================================
NOTIFICATION SYSTEM - DEPLOYMENT GUIDE
=================================================================

This guide shows how to deploy the notification system with automatic
and manual SMS/Email sending.

=================================================================
STEP 1: CREATE DATABASE TABLES
=================================================================

1. Open Supabase Dashboard → SQL Editor
2. Copy and run: CREATE_NOTIFICATION_TABLES.sql
3. Verify tables created: notification_settings, notification_contacts, notification_history

=================================================================
STEP 2: DEPLOY SUPABASE EDGE FUNCTIONS
=================================================================

Prerequisites:
- Install Supabase CLI: npm install -g supabase
- Login: supabase login

Deploy Functions:

1. Link your project:
   supabase link --project-ref YOUR_PROJECT_REF

2. Deploy send-notification function:
   supabase functions deploy send-notification

3. Deploy notification-cron function:
   supabase functions deploy notification-cron

=================================================================
STEP 3: SET ENVIRONMENT VARIABLES
=================================================================

In Supabase Dashboard → Edge Functions → Settings:

Add these secrets:

RESEND_API_KEY=re_xxxxxxxxxxxxx
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxxxxxxx
TWILIO_PHONE_NUMBER=+1234567890

How to get API keys:
- Resend: https://resend.com (free 3,000 emails/month)
- Twilio: https://www.twilio.com/try-twilio (free $15 credit)

=================================================================
STEP 4: SETUP AUTOMATIC NOTIFICATIONS (CRON)
=================================================================

In Supabase Dashboard → Edge Functions → notification-cron:

1. Click "Add Cron Schedule"
2. Set schedule: "* * * * *" (runs every minute)
3. The function will:
   - Check current time
   - Find enabled slots matching current time
   - Send notifications automatically
   - Only run Monday-Friday

Alternative: Use external cron service (cron-job.org) to call:
https://YOUR_PROJECT_REF.supabase.co/functions/v1/notification-cron

=================================================================
STEP 5: CONFIGURE IN ADMIN PANEL
=================================================================

1. Login as admin
2. Go to Settings → Notifications
3. Set 3 time slots (e.g., 10:10 AM, 10:30 AM, 6:00 PM)
4. Enable the slots you want
5. Add HR contacts with email and/or phone
6. Enable contacts

=================================================================
STEP 6: TEST MANUAL SENDING
=================================================================

1. Go to Reports page
2. Click "Send Alert" button
3. Select time slot
4. Click "Send Notification"
5. Check:
   - Toast notification shows success
   - HR contacts receive SMS and Email
   - notification_history table has records

=================================================================
STEP 7: TEST AUTOMATIC SENDING
=================================================================

1. Set a slot time to current time + 2 minutes
2. Enable that slot
3. Wait for the time
4. Check:
   - Cron function runs (check Edge Function logs)
   - Notifications sent automatically
   - notification_history table updated

=================================================================
TROUBLESHOOTING
=================================================================

Edge Function Not Working:
- Check function logs in Supabase Dashboard
- Verify environment variables are set
- Test function manually: supabase functions serve

No Notifications Sent:
- Check if contacts are enabled
- Verify API keys are correct
- Check Resend/Twilio dashboards for errors
- Review notification_history table for error messages

Cron Not Running:
- Verify cron schedule is active
- Check Edge Function logs
- Ensure slots are enabled
- Confirm it's a weekday (Mon-Fri)

SMS Not Delivered:
- For Twilio trial: verify recipient numbers in console
- Check phone number format: +919876543210
- Verify Twilio account balance

Email Not Delivered:
- Check spam folder
- Verify email addresses are correct
- Check Resend dashboard for delivery status

=================================================================
ARCHITECTURE
=================================================================

Manual Trigger Flow:
1. Admin clicks "Send Alert" in Reports page
2. Frontend calls notificationTriggerService.triggerNotification()
3. Service calls Supabase Edge Function: send-notification
4. Edge Function:
   - Gets enabled contacts from database
   - Sends emails via Resend API
   - Sends SMS via Twilio API
   - Logs results to notification_history
5. Returns success/failure count to frontend

Automatic Trigger Flow:
1. Cron runs notification-cron function every minute
2. Function checks current IST time
3. Finds enabled slots matching current time
4. For each slot:
   - Gets today's attendance data
   - Calls send-notification function
   - Logs results
5. Only runs Monday-Friday
