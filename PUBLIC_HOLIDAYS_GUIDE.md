# Public Holidays Setup Guide

## How to Set Up Annual Holidays

As an admin, you can set up holidays for the entire year in one go. Here's how:

### Step 1: Navigate to Holiday Calendar
1. Login as admin
2. Go to **Admin → Holiday Calendar**

### Step 2: Set Up Public Holidays
Click on each date and:
1. Select **Holiday Type**: Public Holiday or Festival
2. Enter the **Reason** (e.g., "Republic Day", "Holi")
3. Select **All Employees** (or specific employees)
4. Click **Confirm Holiday**

### Step 3: Visual Indicators
- **Red dates** = Public holidays/festivals (shown to all)
- **Amber dates** = Other holidays (company events, etc.)
- **Green date** = Today
- Holiday names appear below the date

## Quick Setup Instructions

### For All Employees:
1. Click on the date (e.g., January 26)
2. Holiday Type: **Public Holiday**
3. Reason: **Republic Day**
4. Click **Select All** to include all employees
5. Click **Confirm Holiday**

### For Specific Departments/Employees:
1. Click on the date
2. Holiday Type: **Company Event** or **Other**
3. Reason: (e.g., "Team Outing", "Training Day")
4. Select only specific employees
5. Click **Confirm Holiday**

### For Weekly Holidays:
1. Click on the day header (e.g., **SAT** or **SUN**)
2. Select employees who have that day off
3. Click **Confirm Holiday**

---

## Best Practices

1. **Set up at the beginning of the year** - Add all known public holidays in January
2. **Use consistent naming** - "Diwali" not "Deepavali" or "Diwali Festival"
3. **Mark as Public Holiday or Festival** - This shows them in red on the calendar
4. **Include all employees** - For national holidays, select all employees
5. **Review monthly** - Check if any new holidays need to be added

## Benefits

✅ **One-time setup** - Set holidays once for the whole year

✅ **Automatic attendance** - Employees won't be marked absent on holidays
✅ **Employee visibility** - Employees can see their holidays in advance
✅ **Easy management** - Delete holidays if assigned by mistake
